# זירה: סימולטור גאופוליטי למודלי שפה

אתר שבו מודלי שפה מנהלים מדינות אמיתיות, תור אחר תור, וכלים להשוות ביניהם: מי מסלים, מי משתף פעולה, ומי אומר דבר אחד ועושה אחר. התוכנית המלאה נמצאת ב-[`docs/PLAN.md`](../docs/PLAN.md).

## איך זה עובד

- **הכול בדפדפן.** אין שרת. הסימולציה רצה בדפדפן של המשתמש, והקריאות למודלים יוצאות ישירות ממנו לספק.
- **כל משתמש מביא מפתח משלו.** המפתחות נשמרים ב-`localStorage` (או ב-`sessionStorage`, אם המשתמש ביקש לא לזכור אותם) ולא עוברים דרך שום שרת שלנו. כך אפשר לפרסם את האתר בלי שהמכסה של מישהו אחד תנוצל.
- **ספקים נתמכים:** Gemini, Claude (Anthropic), OpenAI, ו-OpenRouter, שנותן גישה ל-Llama, DeepSeek ומודלים פתוחים נוספים.
- **מודל דמו** בוחר פעולות לפי כללים פשוטים, כדי שאפשר יהיה לנסות את האתר בלי מפתח. ההתנהגות שלו לא אומרת דבר על מודלים אמיתיים.
- **שמירה:** ריצות נשמרות ב-IndexedDB אחרי כל תור. ריצה שנעצרה, למשל כי המכסה היומית של Gemini נגמרה או כי הדף נסגר, ממשיכה מהתור האחרון שנשמר.

## פיתוח

```bash
cd zira
npm ci
npm run dev        # http://localhost:5173
npm test           # בדיקות המנוע והספקים
npm run build      # בנייה ל-dist/
npm run world      # בנייה מחדש של public/world-he.json מ-Natural Earth
```

## פרסום ל-GitHub Pages

ה-workflow שב-`.github/workflows/zira.yml` מריץ בדיקות ובנייה בכל push, ומפרסם את האתר כשיש שינוי ב-`main`.

הגדרה חד-פעמית: **Settings → Pages → Build and deployment → Source: GitHub Actions**. אחרי ה-merge ל-`main` האתר יעלה בכתובת `https://<user>.github.io/ai-ethics-tests/`.

## מבנה הקוד

| תיקייה | תפקיד |
|---|---|
| `src/engine/` | מנוע הסימולציה, בלי תלות ב-React: פעולות, מצב העולם, בניית ההנחיות, אימות התשובות, פתרון התור, מדדים, וניהול הריצה כולל מגבלות קצב |
| `src/providers/` | חיבור לכל ספק מודלים, והמודל המדומה |
| `src/store/` | הגדרות ומפתחות (`localStorage`), וריצות (IndexedDB) |
| `src/ui/` | המסכים: הגדרה, הרצה, ניתוח, ומודלים ומפתחות |
| `scripts/build-world.mjs` | יוצר את קובץ המפה: גבולות Natural Earth בהקרנת Equal Earth, שמות בעברית ונתוני פתיחה |
